# カレンダー共有アプリ 要件書

## プロジェクト概要
家族・グループ向けのカレンダー共有アプリ。複数のカレンダーをグループ内で共有し、共同でスケジュール管理を行うことを目的とする。

## ユーザーストーリー

### US-1: 新規登録
- ユーザーはメールアドレスとパスワードで登録できる
- 登録後は自動的にマイプロフィール画面に遷移

### US-2: グループの作成
- ユーザーは新しいグループを作成できる
- グループ作成時に招待リンクが自動生成される
- 1ユーザー = 1グループ（固定）

### US-3: グループへの参加
- 招待リンク（`/join/:token`）で誰でも参加可能
- セキュリティ制限なし

### US-4: カレンダーの管理
- グループ内でユーザーが自由にカレンダーを作成・削除できる
- カレンダーの例：「プライベート」「仕事用」など
- グループ内全員がすべてのカレンダーを閲覧可能

### US-5: イベントの作成・編集
- ユーザーはカレンダー内にイベントを作成
- イベント編集・削除は作成者のみ
- 他のメンバーは閲覧のみ

### US-6: イベント情報の表示
- イベント一覧を月単位で表示
- イベント情報：タイトル・日時・メモ・色

## 機能要件

### 認証
- **メール認証**: メールアドレス＋パスワード（Supabase Auth）
- **ログイン / ログアウト**: 標準的な認証フロー

### グループ・ユーザー管理
- 1ユーザー = 1グループ固定
- 招待リンク経由の参加（セキュリティ制限なし）
- グループ内全員が同じカレンダーセットを閲覧可能

### カレンダー管理
- グループ内で複数カレンダーを作成・削除可能
- 各カレンダーには名前と色を設定
- ユーザーはカレンダーのON/OFF切り替えが可能（UI機能）

### イベント管理
| 項目 | 内容 |
|------|------|
| **タイトル** | 必須 |
| **日時** | 終日 or 時間指定（両対応） |
| **メモ** | 任意 |
| **色** | 任意（プリセットカラーから選択） |
| **編集権限** | 作成者のみ編集・削除可能 |
| **閲覧** | グループ内全員が閲覧可能 |

### 通知・リアルタイム
- **リアルタイム同期**: 不要（画面更新で十分）
- **通知**: なし

## UIデザイン要件

- **参考アプリ**: LifeBear
- **ビジュアル**: 色分けされたイベントバッジ、複数カレンダーの重ね表示
- **レイアウト**: 月表示メイン、シンプルな縦長デザイン
- **マルチタブUI**: ToDo・ノートなども将来的に統合可能な構造

## ユーザーセッション

### セッション1: ログイン前
1. ランディングページ
2. 新規登録 / ログイン

### セッション2: ログイン後（グループ未参加）
1. グループ作成ページ
   - グループ作成 → 招待リンク生成
   - または、招待リンク入力で参加

### セッション3: グループ参加後
1. カレンダー選択画面
2. 月別カレンダー表示（複数カレンダーの重ね表示）
3. イベント追加・編集・削除

## 制約・非機能要件

| 項目 | 内容 |
|------|------|
| **プラットフォーム** | Web のみ |
| **ブラウザ互換性** | 最新版Chrome/Firefox/Safari |
| **レスポンス時間** | API 応答時間 < 200ms |
| **スケーラビリティ** | 初期段階は小規模（100ユーザー程度）対応 |
| **データ保持** | 無期限（削除手段は後日検討） |
