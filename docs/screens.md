# 画面設計書 - カレンダー共有アプリ

## 1. 画面一覧

| #   | 画面名                 | パス                  | 認証 | グループ             |
| --- | ---------------------- | --------------------- | ---- | -------------------- |
| 1   | ログイン               | `/login`              | 不要 | 不問                 |
| 2   | 新規登録               | `/register`           | 不要 | 不問                 |
| 3   | オンボーディング       | `/onboarding`         | 必要 | 未所属のみ           |
| 4   | グループ参加           | `/join/[token]`       | 必要 | 未所属のみ           |
| 5   | プライベートカレンダー | `/`                   | 必要 | 所属済み             |
| 6   | イベント作成           | `/events/new`         | 必要 | 所属済み             |
| 7   | イベント編集           | `/events/[id]/edit`   | 必要 | 所属済み・作成者のみ |
| 8   | 仕事用カレンダー       | `/work`               | 必要 | 所属済み             |
| 9   | シフトパターン一覧     | `/work/patterns`      | 必要 | 所属済み             |
| 10  | シフトパターン新規作成 | `/work/patterns/new`  | 必要 | 所属済み             |
| 11  | シフトパターン編集     | `/work/patterns/[id]` | 必要 | 所属済み・本人のみ   |

## 4. 各画面の詳細設計

---

### 画面1: ログイン `/login`

**目的**: メールアドレス＋パスワードでログイン

**レイアウト**

```
┌──────────────────────────┐
│      アプリロゴ            │
│                          │
│  [メールアドレス入力]       │
│  [パスワード入力]          │
│                          │
│  [ログインボタン]          │
│                          │
│  新規登録はこちら ──▶      │
└──────────────────────────┘
```

**コンポーネント構成**

```
page.tsx
└── LoginForm
    ├── <input type="email" />         メールアドレス
    ├── <input type="password" />      パスワード
    ├── <button> ログイン              送信ボタン
    └── <Link href="/register">        新規登録リンク
```

**状態・バリデーション**

- メール形式チェック・パスワード必須
- ログイン失敗時: エラーメッセージ表示
- ログイン成功: グループ所属 → `/` / 未所属 → `/onboarding`

### 画面2: 新規登録 `/register`

**目的**: アカウント作成

**レイアウト**

```
┌──────────────────────────┐
│      アプリロゴ            │
│                          │
│  [表示名入力]             │
│  [メールアドレス入力]       │
│  [パスワード入力]          │
│                          │
│  [登録ボタン]             │
│                          │
│  ログインはこちら ──▶      │
└──────────────────────────┘
```

**コンポーネント構成**

```
page.tsx
└── RegisterForm
    ├── <input type="text" />          表示名
    ├── <input type="email" />         メールアドレス
    ├── <input type="password" />      パスワード（8文字以上）
    ├── <button> 登録する              送信ボタン
    └── <Link href="/login">           ログインリンク
```

**状態・バリデーション**

- パスワード8文字以上
- メール重複時: 「このメールアドレスはすでに登録されています」
- 登録成功 → `/onboarding`

### 画面3: オンボーディング `/onboarding`

**目的**: グループ未所属ユーザーがグループを作成する

**レイアウト**

```
┌──────────────────────────┐
│  グループを作成してください  │
│                          │
│  [グループ名入力]          │
│  [作成ボタン]             │
│                          │
│  ─────── 作成後 ─────── │
│                          │
│  招待リンク               │
│  [https://...][コピー]    │
│                          │
│  [カレンダーへ進む]        │
└──────────────────────────┘
```

**コンポーネント構成**

```
page.tsx
├── OnboardingForm（グループ名入力・作成）
│   ├── <input type="text" />          グループ名
│   └── <button> 作成する
└── InviteLinkCard（作成後に表示）
    ├── <p> 招待リンク表示
    ├── <button> コピー               クリップボードコピー
    └── <Link href="/"> カレンダーへ進む
```

**状態管理**

- `step: 'create' | 'invite'` で表示切替
- 作成後: invite_tokenを含むURLを表示

### 画面4: グループ参加 `/join/[token]`

**目的**: 招待リンク経由でグループに参加

**レイアウト**

```
┌──────────────────────────┐
│  「〇〇家」に参加しますか？  │
│                          │
│  グループ名: 〇〇家        │
│  メンバー数: 3人           │
│                          │
│  [参加する]               │
│  [キャンセル]             │
└──────────────────────────┘
```

**コンポーネント構成**

```
page.tsx（サーバーコンポーネント: tokenからグループ情報取得）
└── JoinGroupCard
    ├── グループ名・メンバー数表示
    ├── <button> 参加する             POST /groups/join/:token
    └── <Link href="/onboarding"> キャンセル
```

**状態・バリデーション**

- 未ログイン: `/login?redirect=/join/[token]` にリダイレクト
- すでにグループ所属済み: 「すでにグループに所属しています」
- 無効トークン: 「招待リンクが無効です」
- 参加成功 → `/`

### 画面5: プライベートカレンダー `/`

**目的**: グループ共有イベントの閲覧・管理（メイン画面）

**レイアウト**

```
┌──────────────────────────┐
│ 2026        [P][W] ‹ ›  │  ← CalendarHeader
│ 6月                      │
│ 日 月 火 水 木 金 土      │
│─────────────────────────│
│  1  2  3  4  5  6  7   │
│        🟦片岡 🟪振り込み│  ← DayCell + EventBadge
│  8  9 10 11 12 13 14   │  ← CalendarGrid
│   🟦木村   🟦納期会     │
│ ...                      │
│──────── ドロワー ────────│  ← DayDrawer（日付タップ時）
│ 6月12日（金）             │
│ 18:00 ● 納期会           │
│                          │
│                      [＋]│  ← FAB
└──────────────────────────┘
│ 🏠 プライベート  💼 仕事  │  ← BottomNav
└──────────────────────────┘
```

**コンポーネント構成**

```
page.tsx
├── CalendarHeader
│   ├── 年月表示（YYYY年M月）
│   ├── カレンダー切替トグル（[P][W]ボタン）   ← 表示中は `/`、もう一方は `/work`
│   ├── 月移動ボタン（‹ ›）
│   └── 曜日ヘッダー（日〜土）
│
├── CalendarGrid
│   └── DayCell × 日数分
│       ├── 日付数字（今日はハイライト）
│       └── EventBadge × イベント数分
│           └── タイトル・背景色
│
├── DayDrawer（selectedDate != null のとき表示）
│   ├── ドラッグハンドル
│   ├── 日付ヘッダー + 閉じるボタン
│   ├── EventRow × イベント数分
│   │   ├── カラードット
│   │   ├── 時刻（終日 or HH:MM）
│   │   ├── タイトル
│   │   └── 編集ボタン（作成者のみ表示）──▶ /events/[id]/edit
│   └── 「予定なし」（イベントが0件のとき）
│
└── FAB（＋ボタン） ──▶ /events/new
```

**状態管理**

- `selectedDate: string | null` 選択日付
- `month: { year, month }` 表示月
- `events: Event[]` SWRでフェッチ

**目的**: プライベートカレンダーにイベントを作成（LifeBearライクUI）

```
┌──────────────────────────┐
│ ×  予定作成        [保存]│
│──────────────────────────│
│ 予定名                   │

│ 金曜日  →  金曜日  [終日]│

│──────────────────────────│
│ 🗓 色・カレンダー        │
│   ● プライベート    ✓   │

│    詳細を表示             │

│ （展開後）               │
│ 📍 場所                  │
│ 💬 メモ                  │
└──────────────────────────┘
```

**コンポーネント構成**

```
page.tsx
└── EventForm（新規モード）
    ├── ヘッダー
    │   ├── <button> × ──▶ /（キャンセル）
    │   └── <button> 保存
    ├── <input> タイトル（予定名・大きめフォント）
    ├── DateTimeSection
    │   ├── 開始日時ピッカー

### 画面7: イベント編集 `/events/[id]/edit`

**目的**: 既存イベントの編集・削除（作成者のみアクセス可能）

**レイアウト**: 画面6とほぼ同一。差分のみ記載

```
┌──────────────────────────┐
│ ×  予定編集        [保存]│
│  ...（画面6と同じ）...   │
│──────────────────────────│
│ [削除する]               │  ← 追加: 削除ボタン（赤）

```

**コンポーネント構成**

```
page.tsx（サーバーコンポーネント: イベント取得・権限チェック）
└── EventForm（編集モード）

- 保存/削除成功 → `/`

## 5. 共通コンポーネント詳細

### BottomNav

画面5・8・9・10・11で常時表示。画面6・7（イベントフォーム）は全画面表示のため非表示。現在地をハイライト。

```
┌──────────────────────────┐
│  🏠          💼          │
│ プライベート   仕事用     │
└──────────────────────────┘
```

| タブ         | アイコン | リンク  |
| ------------ | -------- | ------- |
| プライベート | 🏠       | `/`     |
| 仕事用       | 💼       | `/work` |

### CalendarHeader

画面5・8で共通使用。

| 要素           | 説明                              |
| -------------- | --------------------------------- |
| 年表示         | YYYY（小さめ）                    |
| 月表示         | M月（大きめ・太字）               |
| カレンダー切替 | `[P]`=プライベート / `[W]`=仕事用 |
| 月移動         | ‹（前月）› （次月）               |
| 曜日ヘッダー   | 日〜土（日=赤・土=青）            |

### Drawer / ShiftSelectPanel

タップで下から展開するボトムシート。

| プロパティ | 型         | 説明                   |
| ---------- | ---------- | ---------------------- |
| `isOpen`   | boolean    | 表示状態               |
| `onClose`  | () => void | 閉じるコールバック     |
| `date`     | string     | 対象日付（YYYY-MM-DD） |

### ColorPicker

イベント色・シフトパターン色の選択UI。

```
● ● ● ● ● ● ● ● ● ●
赤 橙 黄 緑 青緑 青 紫 紫 灰 黒
```

| プロパティ | 型                      | 説明                                       |
| ---------- | ----------------------- | ------------------------------------------ |
| `value`    | string                  | 選択中のHEXカラー                          |
| `onChange` | (color: string) => void | 選択コールバック                           |
| `colors`   | string[]                | 選択肢（`SHIFT_COLORS` or `EVENT_COLORS`） |

## 6. 認証ガード設計

Next.js Middleware で制御。

```
middleware.ts
├── 未認証 + 保護ルート → /login にリダイレクト
├── 認証済み + /login, /register → / にリダイレクト
└── 認証済み + グループ未所属 + 保護ルート（/join 以外）→ /onboarding にリダイレクト
```

| ルート                                        | 未認証     | 認証済み・グループ未所属 | 認証済み・所属済み |
| --------------------------------------------- | ---------- | ------------------------ | ------------------ |
| `/login`, `/register`                         | ✅ 表示    | → `/`                    | → `/`              |
| `/onboarding`                                 | → `/login` | ✅ 表示                  | → `/`              |
| `/join/[token]`                               | → `/login` | ✅ 表示                  | エラー表示         |
| `/`, `/work`, `/events/*`, `/work/patterns/*` | → `/login` | → `/onboarding`          | ✅ 表示            |
